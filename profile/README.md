# Aegispeak

**Software engineering for payments, security and regulated industries.**

Aegispeak is a software engineering and product company in Lahore, Pakistan. We have delivered
software since 2004, first as Aquilinesoft.

## What we do

- **Custom software and SaaS,** cloud on AWS and legacy modernization.
- **Payments engineering** for payment service providers, processors, orchestration platforms
  and subscription businesses.
- **Security engineering** and security software.
- **AI features inside products,** with evaluation, guardrails, human review and audit trails.

## How we work

Written specifications before building, prototypes for early feedback, tracked changes to code
and design, test plans and automated tests, and clear acceptance criteria for every deliverable.

Client work lives in our clients' repositories, so little of it appears here.
